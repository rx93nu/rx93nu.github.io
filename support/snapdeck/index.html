덮기 전 지원

최종 업데이트: 2026년 8월 8일

덮기 전 사용 중 궁금한 점이나 문제가 있다면 아래 자주 묻는 질문을 확인해 주세요. 해결되지 않으면 문의 이메일로 연락 주시기 바랍니다.

촬영한 페이지가 서버로 전송되나요?

아니요. 이미지와 OCR 처리는 모두 사용자의 기기 안에서 수행됩니다. 보상형 광고를 선택한 경우에만 광고 요청이 네트워크를 사용합니다.

카메라 또는 사진을 사용할 수 없어요.

홈의 오류 안내에서 설정 열기를 누르고 덮기 전의 카메라 또는 사진 권한을 허용해 주세요. 권한을 허용하지 않아도 샘플 학습과 저장된 세트 복습은 사용할 수 있습니다.

저장 공간을 줄이고 싶어요.

설정에서 미사용 이미지를 즉시 정리하거나 특정 세트 또는 모든 학습 데이터를 삭제할 수 있습니다.

문제를 신고하려면 무엇을 보내야 하나요?

설정의 진단 정보 내보내기로 만든 JSON 파일과 문제가 발생한 단계를 함께 보내 주세요. 진단 파일에는 학습 원문, 정답과 이미지 경로가 포함되지 않습니다.

덮기 전（Deopgi-jeon）サポート

最終更新日: 2026年8月8日

덮기 전（Deopgi-jeon）のご利用中に不明な点や問題がある場合は、以下の よくある質問をご確認ください。解決しない場合は、お問い合わせメール までご連絡ください。

撮影したページはサーバーに送信されますか？

いいえ。画像とOCR処理はすべてユーザーの端末内で行われます。リワード 広告を選択した場合にのみ、広告リクエストがネットワークを使用します。

カメラまたは写真が使えません。

ホームのエラー案内で設定を開くをタップし、本アプリの カメラまたは写真の権限を許可してください。権限を許可しなくても、 サンプル学習と保存済みセットの復習はご利用いただけます。

ストレージ使用量を減らしたいです。

設定から未使用の画像をすぐに削除したり、特定のセットまたはすべての 学習データを削除したりできます。

問題を報告するには何を送ればよいですか？

設定の診断情報のエクスポートで作成したJSONファイルと、 問題が発生した手順をあわせてお送りください。診断ファイルには学習内容の 原文、正解、画像パスは含まれません。

Deopgi-jeon Support

Last updated: August 8, 2026

If you have a question or run into a problem while using Deopgi-jeon, please check the frequently asked questions below. If your issue is not resolved, contact us by email.

Are captured pages sent to a server?

No. Images and OCR processing are handled entirely on the user's device. Only when a user chooses to view a rewarded advertisement does the ad request use the network.

I can't use the camera or photos.

Tap Open Settings in the error notice on the home screen and allow the camera or photo permission for Deopgi-jeon. Even without these permissions, you can still use sample learning materials and review saved decks.

I want to reduce storage usage.

In Settings, you can immediately remove unused images, or delete a specific deck or all learning data.

What should I send to report a problem?

Please send the JSON file created with Export Diagnostics in Settings, along with the steps that led to the problem. The diagnostic file does not include the original learning text, answers, or image paths.
