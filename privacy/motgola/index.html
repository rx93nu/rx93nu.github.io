시행일: 2026년 8월 4일

처리하는 정보

못골라은 촬영 이미지, OCR 텍스트, 생성 카드와 풀이 기록을 사용자의 기기 안에서만 처리합니다. 이 학습 콘텐츠를 못골라 운영 서버로 전송하지 않으며 계정이나 클라우드 동기화를 제공하지 않습니다.

사용자가 보상형 광고를 선택하면 Google Mobile Ads SDK가 광고 제공, 빈도 제한, 부정 사용 방지와 동의 처리를 위해 기기·광고 관련 정보를 네트워크로 처리할 수 있습니다. 필요한 지역에서는 Google User Messaging Platform을 통해 개인정보 선택권을 제공합니다.

권한

  • 카메라: 학습 페이지 촬영
  • 사진: 사용자가 선택한 학습 페이지 가져오기
  • 인터넷(Android): 사용자가 선택한 보상형 광고 요청

권한을 거부해도 샘플 학습과 저장된 세트 복습은 사용할 수 있습니다.

보존과 삭제

저장된 세트와 임시 작업에 연결된 이미지는 사용자가 삭제할 때까지 기기에 남습니다. 연결되지 않은 이미지는 7일 후 자동 삭제됩니다. 설정에서 미사용 이미지 즉시 정리, 특정 세트 삭제 및 모든 로컬 데이터 삭제를 실행할 수 있습니다.

진단 정보

사용자가 직접 내보내기를 선택한 경우 앱 버전, OS 버전, 데이터 개수와 저장 용량을 포함하는 진단 파일을 만듭니다. OCR 원문, 카드 내용, 정답과 이미지 경로는 포함하지 않습니다. 전송 대상은 사용자가 공유 화면에서 직접 선택합니다.

motgola Privacy Policy

Effective date: August 4, 2026

Information We Process

motgola processes captured images, OCR text, generated study cards, and quiz records only on the user's device. motgola does not transmit this learning content to its own servers and does not provide accounts or cloud synchronization.

When a user chooses to view a rewarded advertisement, the Google Mobile Ads SDK may process device- and advertising-related information over the network to deliver ads, apply frequency limits, prevent abuse, and manage consent. Where required, privacy choices are provided through the Google User Messaging Platform.

Permissions

  • Camera: Capture a study page.
  • Photos: Import a study page selected by the user.
  • Internet (Android): Request a rewarded ad selected by the user.

Users can continue to use sample learning materials and review saved decks even if they deny these permissions.

Retention and Deletion

Images linked to saved decks or unfinished work remain on the device until the user deletes them. Unlinked images are automatically deleted after seven days. In Settings, users can immediately remove unused images, delete a specific deck, or delete all locally stored data.

Diagnostic Information

When a user explicitly chooses to export diagnostics, motgola creates a diagnostic file containing the app version, OS version, item counts, and storage usage. It does not include the original OCR text, card content, answers, or image paths. The user selects the recipient through the device's share interface.

Third-Party Processing

  • Google Mobile Ads / User Messaging Platform: Rewarded advertising and region-specific privacy choices.

Google's processing is governed by Google's privacy policy and advertising disclosures.

Children

The initial service is intended for users aged 14 and older and does not direct advertising specifically to children.
