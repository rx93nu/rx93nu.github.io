표정 배틀 지원

표정 배틀(Face Battle)을 이용해 주셔서 감사합니다. 문제가 생겼거나 궁금한 점이 있으면 아래 내용을 먼저 확인해 주세요. 해결되지 않으면 이메일로 문의해 주시면 도와드리겠습니다.

보통 2~3일 이내에 답변드립니다. 문제 상황을 문의하실 때 아래 정보를 함께 적어주시면 훨씬 빠르게 확인할 수 있습니다.

  • 기기 모델 (예: iPhone 15, Galaxy Z Flip5)
  • OS 버전 (예: iOS 18.4, Android 15)
  • 앱 버전 (App Store / Google Play의 앱 상세 페이지에서 확인)
  • 문제가 생긴 화면과 그때의 상황

게임 방법

  1. 함께할 사람들의 이름을 등록합니다 (2~8명).
  2. 모두에게 같은 미션 표정이 제시됩니다.
  3. 한 명씩 순서대로 도전 — 3-2-1 카운트다운 후 3초간 측정합니다.
  4. 표정 정확도를 0~100점으로 채점하고, 가장 점수가 높았던 순간을 스틸컷으로 남깁니다.
  5. 5라운드 합산 점수로 최종 순위가 결정됩니다.

폰 한 대를 돌려가며 하는 패스 앤 플레이 게임이라 인터넷 연결이나 계정이 필요 없습니다.

자주 묻는 질문

얼굴이 인식되지 않아요

  • 얼굴이 화면 안에 충분히 크게 들어오도록 폰을 얼굴에서 30~50cm 정도 떨어뜨려 주세요.
  • 역광(창문·조명을 등지는 상황)에서는 인식률이 크게 떨어집니다. 빛이 얼굴 쪽으로 오는 방향에서 플레이해 주세요.
  • 너무 어두운 곳에서는 인식이 어렵습니다.
  • 마스크, 선글라스, 얼굴을 가리는 머리카락은 인식을 방해합니다.
  • 카메라 렌즈에 지문이나 이물질이 없는지 확인해 주세요.

카메라 권한을 실수로 거부했어요

표정 채점에는 전면 카메라가 반드시 필요합니다. 권한을 거부하셨다면 기기 설정에서 다시 허용해 주세요.

  • iPhone: 설정 → 표정 배틀 → 카메라 켜기
  • Android: 설정 → 애플리케이션 → 표정 배틀 → 권한 → 카메라 허용

표정을 지었는데 점수가 잘 안 올라요

미션은 특정 표정 근육의 움직임만 확인합니다. 예를 들어 "눈썹은 그대로 두고 활짝 웃기" 미션은 입꼬리가 올라가더라도 눈썹이 함께 올라가면 점수가 깎입니다. 화면의 실시간 게이지를 보면서 어떤 동작에서 점수가 오르는지 확인하며 조절해 보세요. 표정은 개인차가 커서 어려움 난도 미션은 실제로 잘 안 올라가는 것이 정상입니다.

턴을 진행할 수 없을 때는 어떻게 하나요

촬영 화면의 턴 건너뛰기 버튼을 누르면 0점으로 처리되고 다음 순서로 넘어갑니다. 카메라를 쓸 수 없는 상황에서도 게임 흐름은 끝까지 진행할 수 있습니다.

보상형 광고를 다 봤는데 보상을 못 받았어요

보상은 광고를 끝까지 시청했을 때 지급됩니다. 중간에 닫으면 지급되지 않습니다. 끝까지 보셨는데도 지급되지 않았다면 네트워크가 불안정했을 수 있으니 다시 시도해 주세요. 광고를 불러오지 못하는 경우에는 파티 흐름이 끊기지 않도록 해당 기능을 그냥 열어드립니다.

해금한 프레임 팩·미션 팩이 다시 잠겼어요

보상형 광고로 해금한 항목은 현재 게임 세션 동안 유지됩니다. 앱을 완전히 종료했다가 다시 실행하면 초기 상태로 돌아갑니다.

스틸컷과 리캡 콜라주는 어디에 저장되나요

게임 중 촬영된 스틸컷은 앱 안에만 임시로 존재하며 세션이 끝나면 사라집니다. 공유·저장 버튼을 눌러 직접 내보낸 사진만 기기에 남습니다. 저장이 되지 않는다면 사진 접근 권한이 허용되어 있는지 확인해 주세요.

인터넷 없이도 플레이할 수 있나요

네. 얼굴 인식과 채점은 전부 기기 안에서 처리되므로 오프라인에서도 게임이 동작합니다. 다만 광고는 표시되지 않습니다.

내 얼굴 데이터가 서버로 전송되나요

아니요. 얼굴 인식과 표정 분석은 전부 기기 안에서(온디바이스) 이루어지며, 카메라 영상이나 얼굴 이미지가 외부 서버로 전송되거나 저장되지 않습니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

앱이 느리거나 게이지가 끊겨요

다른 앱을 종료해 메모리를 확보하고, 저전력 모드를 끈 뒤 다시 시도해 주세요. 기기가 많이 뜨거워진 상태에서도 인식 속도가 떨어질 수 있습니다.

몇 명까지 함께할 수 있나요

2명부터 8명까지 등록할 수 있습니다. 라운드는 5라운드로 진행됩니다.
